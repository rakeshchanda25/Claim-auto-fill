# Discharge Summary Rendering Specification

- Page Size: Letter Portrait, 1.0in margins
- Primary Font: Arial / Helvetica 10pt (line-height 1.6)
- Banner Headers: Dark Navy background `#1a3a6b` with white text
- Table Styles: 100% width, `#e8eef7` table header background, 1px `#ccc` interior grid lines
- Signature Block: Attending physician signature line, printed name, specialty, NPI, and date stamp
