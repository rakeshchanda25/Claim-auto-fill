# Police Report Rendering Specification

- Page Size: Letter Portrait, 0.9in margins
- Typography: Arial or Helvetica 10pt (line-height 1.5)
- Header: Centered Department name, bold "INCIDENT REPORT" title, thin horizontal rule
- Narrative: Distinct shaded block (`#fafafa`) with a 1px border (`#ccc`)
- Signatures: Reporting officer and date filed signature line at bottom
