# Pharmacy Invoice Rendering Specification

- Page Size: Letter Portrait, 0.85in margins
- Typography: Arial or Helvetica 10pt (line-height 1.5)
- Color Accents: Forest Green (`#2d6a4f`) theme for header bar and table headers
- Structure: Flex header (Pharmacy details left, Invoice meta right), Patient/Prescriber grids, Prescription charges table, Totals breakdown box (`#f0f9f4`)
