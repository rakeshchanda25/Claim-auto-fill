# ACORD 25 Field Glossary

- `producer_agency`: Agency Name & Address
- `insured_name`: Business Entity Name & Address
- `policy_number`: Policy ID (`^POL[A-Z0-9]{9}$`)
- `effective_date`: Policy Effective Date (`MM/DD/YYYY`)
- `expiration_date`: Policy Expiration Date (`MM/DD/YYYY`)
- `general_liability_limit`: Each Occurrence limit (`$1,000,000`)
- `umbrella_limit`: Umbrella aggregate limit (`$2,000,000`)
- `workers_comp_limit`: Workers Comp per employee limit (`$500,000`)
- `certificate_holder`: Holder Name & Mailing Address
