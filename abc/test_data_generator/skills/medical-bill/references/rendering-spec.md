# Medical Bill Rendering Specification

- Geometry: Letter Portrait, 0.85in margins
- Header: Hospital branding top-left, statement dates top-right
- Encounter Note: labeled fill-in rows for Chief Complaint/HPI/Physical Exam/Assessment (a
  `.fval-line` underlined value below each section title), a `.vitals-grid` flex-wrap row of
  BP/HR/Temp/RR/SpO2/Weight, and a Plan section
- Itemized Table: CPT procedure codes with right-aligned charges
- Summary Card: Shaded balance due summary box
