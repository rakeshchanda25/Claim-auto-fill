# EOB Rendering Specification

- Page Size: Letter Landscape, 0.35in margins, single page (landscape to fit the 12-column
  claims table)
- Typography: Arial/Helvetica 9.3pt, Georgia/serif for the document title
- Claim info box: navy-accented (`#1c3457`) left border, claim info on the left, claim
  reference number/date on the right
- Claims table (`table.claims-table`): 12 columns, navy header row (white text), zebra-striped
  data columns, bold navy total row with a heavier top border
- Notes legend: small table below the claims table, bold navy code + description
- Patient Benefit Summary: navy header bar, white body, deductible/OOP sentences
