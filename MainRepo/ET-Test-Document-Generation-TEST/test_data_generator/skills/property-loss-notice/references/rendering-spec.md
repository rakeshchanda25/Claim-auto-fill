# Property Loss Notice Rendering Specification

- Page Size: Letter Portrait, 0.85in margins
- Typography: Arial or Helvetica 10pt (line-height 1.5)
- Color Accents: Rust Brown (`#7b2d00`) header bar and section headers
- Layout: 2-column details grids for Insured details, Loss description, the scenario-specific
  Details section (same `h2`/`.grid2` styling as every other section, omitted when the
  scenario has no facts), Mortgagee information, and Adjuster assignment, ending with
  signature blocks
